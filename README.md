# Starlink Reconnect

Маленькое Android-приложение-«вотчдог», которое работает в связке с официальным
приложением Starlink: как только открытая Wi-Fi сеть с SSID `Starlink`
(имя настраивается) появляется в зоне действия, телефон автоматически
(пере)подключается к ней и удерживает соединение, даже если Android решил, что
«интернета нет» (терминал грузится, ищет спутники и т.п.).

## Как это работает

* **Foreground-сервис** раз в 15 секунд (и при каждом событии Wi-Fi / скана)
  проверяет: подключены ли мы к целевой сети и видна ли она в результатах скана.
  Если сеть видна, а телефон не на ней, сервис принудительно переподключается.
* **Два механизма подключения** используются одновременно:
  1. legacy-API `WifiManager.addNetwork / enableNetwork / reconnect` — единственный
     публичный способ *активно* заставить телефон подключиться к нужному SSID из
     фона. На Android 10+ он работает только для приложений с `targetSdk 28`,
     поэтому приложение намеренно таргетит API 28 (это сайдлоад-утилита, не
     Play Store).
  2. `WifiNetworkSuggestion` (Android 10+) — система сама автоподключается к
     подсказанной сети, даже если процесс приложения убит.
* **`NetworkRequest` на TRANSPORT_WIFI** удерживает Wi-Fi-линк живым, когда
  Android считает сеть «без интернета» и хочет спрыгнуть на мобильные данные.
* **Автозапуск** после перезагрузки телефона и после обновления APK, если
  вотчдог был включён.
* **Уведомление о подключении**: тап по нему открывает приложение Starlink
  (`com.starlink.mobile`), либо его страницу в Play Store, если оно не
  установлено.

## Установка и настройка

1. Скачайте APK: вкладка **Releases** (каждый пуш публикует pre-release
   `build-N`) или артефакт `StarlinkReconnect-apk` в **Actions**.
2. Установите APK (разрешите установку из неизвестных источников).
3. В приложении:
   * укажите SSID (по умолчанию `Starlink`);
   * нажмите **Выдать разрешения** → геолокация (Android требует её, чтобы
     приложение видело Wi-Fi сети);
   * **Разрешить геолокацию «всегда»** — чтобы сканирование работало в фоне;
   * **Отключить оптимизацию батареи** — чтобы сервис не убивали;
   * (Android 11+) **Сохранить сеть в настройках Wi-Fi** — добавит сеть в
     системный список с автоподключением;
   * включите переключатель **Автопереподключение**.
4. Держите системную геолокацию включённой: без неё Android прячет результаты
   сканирования Wi-Fi от всех приложений.

Кнопка **Переподключить сейчас** (и действие в уведомлении) принудительно
рвёт текущую ассоциацию и заново подключается к целевой сети.

## Сборка

Требуется JDK 17, Gradle 8.14+ и Android SDK (compileSdk 34). Зависимостей
нет — только платформенные API.

```bash
gradle assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

Сборку делает GitHub Actions (`.github/workflows/build-apk.yml`). APK
подписывается ключом из `app/keystore/starlink-reconnect.jks.base64` (Gradle
декодирует его в `app/build/keystore/` при сборке). Ключ лежит в репозитории
специально: так каждая CI-сборка подписана одним и тем же ключом, и новую
версию можно ставить поверх старой без удаления. Ключ не секретный и годится
только для сайдлоада.

## Ограничения

* Android 10+ запрещает обычным приложениям напрямую управлять Wi-Fi, если они
  таргетят API 29+. Отсюда `targetSdk 28`; при установке на новых версиях
  Android может появиться предупреждение «приложение создано для старой версии».
* Системную настройку «Автоматически переключаться на мобильные данные»
  приложение изменить не может; `NetworkRequest` лишь не даёт системе
  разорвать Wi-Fi.
* Сканирование Wi-Fi в Android ограничено по частоте (примерно 4 скана за 2
  минуты), поэтому «увидеть» сеть приложение может с задержкой до минуты;
  обычно быстрее, потому что система сканирует и сама.
